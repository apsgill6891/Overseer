# 4. Domain glossary

| Term | Definition |
|---|---|
| Accepted delivery promise | Latest delivery instant/range accepted at checkout; an immutable constraint unless the customer explicitly changes it |
| Agent definition | Versioned metadata describing purpose, execution type, permitted tools, inputs, outputs, and owner |
| Alternative plan | Complete proposed allocation, package, carrier service, cost, timing, evidence, and constraint result |
| Approval | Human authority decision on a specific immutable recommendation version |
| ATP | Available-to-promise inventory after reservations, damage, quarantine, and protected safety stock |
| Batch | Monitoring group for selected independent order runs; not a transaction boundary |
| CTP | Capacity/cutoff feasibility to fulfill within the promise |
| Cross-Border modifier | Additional customs, eligibility, cost, confidence, and approval rules applied to a base profile |
| Evidence | Referenced fact, calculation, estimate, rule result, or source version supporting a decision |
| Goal agent | Bounded workflow coordinating required task capabilities toward an operational outcome |
| Goal profile | Business configuration of objective, constraints, preferences, authority, and escalation—not an agent |
| Guardrail | Non-negotiable safety, authorization, integrity, or compliance control |
| Hard constraint | Condition a plan must satisfy to remain feasible |
| Orchestration agent | Coordinator selecting/revising workflows, responding to events, enforcing checkpoints, and routing authority |
| Preference | Secondary choice applied only among feasible, policy-compliant, promise-satisfying plans |
| Predictive estimate | Model- or distribution-based quantity with confidence/data-quality indicator, such as delivery probability |
| Protected safety stock | Merchant/FC quantity unavailable for ordinary allocation |
| Recommendation version | Immutable snapshot of the selected plan and supporting evidence sent for execution or approval |
| Reservation | Time-bounded claim on inventory preventing double allocation |
| Task capability/agent | Narrow operation producing a validated fact, calculation, or check; may be deterministic |
| Total expected fulfillment cost | Pick/pack + packaging + transport + split + border + expected lateness + expected failure/reship cost |
| Workflow checkpoint | Safe persisted boundary where pause, retry, resume, or human intervention is allowed |
